<span style="font-size:11.142857551574707pt;"><b>Objetivos:</b></span>

- <span style="font-size:11.142857551574707pt;color:#0fdffff;">Este tema ayudará a los estudiantes a</span> <span style="font-size:11.142857551574707pt;color:#0fdffff;"><b>planificar</b></span> <span style="font-size:11.142857551574707pt;color:#0fdffff;">y desarrollar su trabajo realizando para ello</span> <span style="font-size:11.142857551574707pt;color:#0fdffff;"><b>cambios</b></span> <span style="font-size:11.142857551574707pt;color:#0fdffff;">efectivos en su</span> <span style="font-size:11.142857551574707pt;color:#0fdffff;"><b>comportamiento</b></span> <span style="font-size:11.142857551574707pt;color:#0fdffff;">y en la forma de organizar su trabajo.</span>  
- <span style="font-size:11.142857551574707pt;color:#0fdffff;">Contribuirá también a que los estudiantes  detecten aquellas</span> <span style="font-size:11.142857551574707pt;color:#0fdffff;"><b>actividades</b></span> <span style="font-size:11.142857551574707pt;color:#0fdffff;">que, actualmente,</span> <span style="font-size:11.142857551574707pt;color:#0fdffff;"><b>ocupan</b></span> <span style="font-size:11.142857551574707pt;color:#0fdffff;">la mayor parte de su tiempo para</span> <span style="font-size:11.142857551574707pt;color:#0fdffff;"><b>planificarlas</b></span> <span style="font-size:11.142857551574707pt;color:#0fdffff;">y</span> <span style="font-size:11.142857551574707pt;color:#0fdffff;"><b>registrarlas</b></span><span style="font-size:11.142857551574707pt;color:#0fdffff;">.</span>  
- <span style="font-size:11.142857551574707pt;color:#0fdffff;">También se les animará a tener en consideración el</span> <span style="font-size:11.142857551574707pt;color:#0fdffff;"><b>equilibrio</b></span> <span style="font-size:11.142857551574707pt;color:#0fdffff;">entre el</span> <span style="font-size:11.142857551574707pt;color:#0fdffff;"><b>trabajo</b></span> <span style="font-size:11.142857551574707pt;color:#0fdffff;">y la</span> <span style="font-size:11.142857551574707pt;color:#0fdffff;"><b>vida</b></span> <span style="font-size:11.142857551574707pt;color:#0fdffff;">a la que aspiran y las medidas que podrían adoptar para que sea una realidad.</span> 
- <span style="font-size:11.142857551574707pt;color:#0fdffff;">Los estudiantes</span> <span style="font-size:11.142857551574707pt;color:#0fdffff;"><b>analizarán su propio enfoque de la gestión del tiempo</b></span> <span style="font-size:11.142857551574707pt;color:#0fdffff;">para el desarrollo de sus actividades profesionales y privadas.</span> 
- <span style="font-size:11.142857551574707pt;color:#0fdffff;">Aprenderán a</span> <span style="font-size:11.142857551574707pt;color:#0fdffff;"><b>establecer metas, priorizar las tareas más importantes y minimizar las distracciones.</b></span> <span style="font-size:11.142857551574707pt;color:#0fdffff;">Con este conocimiento el estudiante puede establecer sus propias prioridades y decidir a qué tarea dedica su tiempo.</span> 

<span style="font-size:11.142857551574707pt;color:#0fdffff;">Una adecuada gestión del tiempo normalmente supone adquirir las siguientes</span> <span style="font-size:11.142857551574707pt;color:#0fdffff;"><b>competencias</b></span> <span style="font-size:11.142857551574707pt;color:#0fdffff;">y  tener claridad respecto a:</span>
- <span style="font-size:11.142857551574707pt;color:#0fdffff;">Qué es realmente importante  y cómo establecer prioridades.</span> 
- <span style="font-size:11.142857551574707pt;color:#0fdffff;">Cómo realizar una planificación realista.</span> 
- <span style="font-size:11.142857551574707pt;color:#0fdffff;">Cómo decir que no y cómo solicitar ayuda.</span> 
- <span style="font-size:11.142857551574707pt;color:#0fdffff;">El manejo de la procrastinación.</span> 
- <span style="font-size:11.142857551574707pt;color:#0fdffff;">Cómo utilizar el tiempo de manera eficiente y eficaz para finalizar los proyectos en periodo de tiempo establecido.</span>

<span style="font-size:11.142857551574707pt;">Para que nuestros planes y proyectos sean realmente productivos, tenemos que aprender a gestionar el tiempo.</span> 

<span style="font-size:11.142857551574707pt;"><b>¿Qué es el tiempo?</b></span> 

<span style="font-size:11.142857551574707pt;">RAE: Período determinado durante el que se realiza una acción o se desarrolla un acontecimiento.</span>

<span style="font-size:11.142857551574707pt;"><b>Nuestro tiempo es limitado y lo peor es que no sabemos cuando acaba...</b></span>

<span style="font-size:11.142857551574707pt;">Me parece importante reflexionar sobre la muerte, de forma regular. El simple hecho de que algún día moriremos… y no sabemos cuándo. Merece la pena leer el cuento "El buscador" de Jorge Bucay (ver Bibliografía).</span> 

<span style="font-size:11.142857551574707pt;">{{NotesAttachment:f83cb7de3c68a40dda0a1ef05f94109d}}</span>
<span style="font-size:11.142857551574707pt;">Esto nos ayuda a recordar que la vida es corta y preciosa, y a tomar la determinación de aprovechar al máximo este regalo.</span>

<span style="font-size:11.142857551574707pt;">Quizás quieras dejar un impacto en el mundo, haciendo el bien y sirviendo a las personas de una manera significativa, con el tiempo limitado que tienes en esta vida.</span>

<span style="font-size:11.142857551574707pt;">Pero es importante hacerlo sin malgastar el tiempo con el trabajo pesado. Solemos ir a las tareas fáciles, manteniéndonos ocupados haciendo un montón de pequeñas cosas. Podrías pasar un año así y no progresar mucho en nada significativo, simplemente mantenerte a flote.</span>

<span style="font-size:11.142857551574707pt;">Hay que tener en cuenta que</span> <span style="font-size:11.142857551574707pt;"><b>el dinero perdido puede recuperarse; el tiempo perdido, no.</b></span>
<span style="font-size:11.142857551574707pt;">Recordemos regularmente que</span> <span style="font-size:11.142857551574707pt;"><b>tenemos un tiempo limitado cada día y cada semana.</b></span> 

<span style="font-size:11.142857551574707pt;color:#ffb718ff;"><b>Dos dimensiones del tiempo:</b></span>

<span style="font-size:11.142857551574707pt;">- Dimensión</span> <span style="font-size:11.142857551574707pt;"><b>interna</b></span><span style="font-size:11.142857551574707pt;">: surge de nuestra percepción y de nuestra gestión del tiempo: depende de nosotros.</span> 
<span style="font-size:11.142857551574707pt;">- Dimensión</span> <span style="font-size:11.142857551574707pt;"><b>externa</b></span> <span style="font-size:11.142857551574707pt;">del tiempo: aquella que la marcan otras personas y que se manifiesta en forma de calendarios,</span> <span style="font-size:11.142857551574707pt;"><i>deadlines</i></span><span style="font-size:11.142857551574707pt;">, plazos, etcétera.</span> 

<span style="font-size:11.142857551574707pt;color:#ffb718ff;"><b>Nuestro tiempo es limitado pero nuestras tareas son aparentemente</b></span> <span style="font-size:17.14285659790039pt;color:#ffb718ff;"><b>ilimitadas</b></span>

<span style="font-size:11.142857551574707pt;">La gestión del tiempo no existe. No podemos manejar el tiempo, el tiempo siempre sigue su curso. Sin embargo, podemos</span>  <span style="font-size:11.142857551574707pt;"><i>gestionamos a nosotros mismos</i></span><span style="font-size:11.142857551574707pt;">, es decir, podemos manejar cómo gestionamos el tiempo:</span> 

<span style="font-size:11.142857551574707pt;">La mayoría de las veces no nos paramos a pensar en cómo gestionamos nuestro tiempo y cómo lo digital nos roba el tiempo, simplemente, actuamos por inercia.</span> <span style="font-size:11.142857551574707pt;"><i>Gestionar adecuadamente el tiempo es</i></span> <span style="font-size:11.142857551574707pt;"><b><i>clave</i></b></span> <span style="font-size:11.142857551574707pt;"><i>en un entorno digital para ser productivos</i></span><span style="font-size:11.142857551574707pt;">.</span> 

<span style="font-size:11.142857551574707pt;color:#202020ff;">En cualquier día, tenemos más cosas que podríamos hacer de lo que realmente podemos hacer.</span> 
<span style="font-size:11.142857551574707pt;color:#202020ff;">Siempre terminaremos el día con tareas pendientes. Esto siempre es cierto: cada año, tenemos muchas más opciones de las que podemos asumir.</span>

<span style="font-size:11.142857551574707pt;color:#202020ff;"><i>Con eso en mente, que nuestro tiempo es limitado y tenemos más tareas / proyectos de los que podemos hacer, esto nos lleva a hacernos una pregunta importante:</i></span>

- <span style="font-size:11.142857551574707pt;color:#202020ff;"><i>¿Cómo aprovechamos al máximo nuestro tiempo limitado?</i></span> 
- <span style="font-size:11.142857551574707pt;color:#202020ff;"><b><i>¿Cuál es la mejor inversión de tu tiempo en cada momento?</i></b></span> 
- <span style="font-size:11.142857551574707pt;color:#202020ff;"><i>¿Con qué tarea significativa puedes aprovechar mejor tu tiempo en este momento?</i></span> 

<span style="font-size:11.142857551574707pt;color:#202020ff;">Y la única forma de responder a eso es responder estas preguntas:</span>

- <span style="font-size:11.142857551574707pt;color:#202020ff;"><i>¿Qué quieres lograr?</i></span> 
- <span style="font-size:11.142857551574707pt;color:#202020ff;"><i>¿Qué</i></span> <span style="font-size:11.142857551574707pt;color:#202020ff;"><b><i>impacto</i></b></span> <span style="font-size:11.142857551574707pt;color:#202020ff;"><i>quieres tener?</i></span> 
- <span style="font-size:11.142857551574707pt;color:#202020ff;"><i>¿Qué sería</i></span> <span style="font-size:11.142857551574707pt;color:#202020ff;"><b><i>significativo</i></b></span> <span style="font-size:11.142857551574707pt;color:#202020ff;"><i>para ti?</i></span> 

<span style="font-size:11.142857551574707pt;color:#202020ff;">Si no conoces las respuestas a estas preguntas, no puedes saber cuál sería la mejor manera de aprovechar tu tiempo.</span> 
<span style="font-size:11.142857551574707pt;color:#202020ff;">No puedes saber qué tareas elegir, porque son todas iguales.</span>
<span style="font-size:11.142857551574707pt;color:#202020ff;">Por eso en la primera parte de este módulo realizamos un proceso de Autoconocimiento y una definición de la marca personal.</span>

<span style="font-size:11.142857551574707pt;color:#ffb718ff;"><b>Ten claro lo que importa</b></span>

- <span style="font-size:11.142857551574707pt;color:#202020ff;"><i>¿Qué es</i></span> <a href="https://mininmamente.us11.list-manage.com/track/click?u=13bc0a11b0785ce6956146549&id=94b51c05c1&e=3ee44a8eed" rel="noopener" class="external-link" target="_blank" style="font-size:11.142857551574707pt;"><i><u>lo que más te importa</u></i></a> <span style="font-size:11.142857551574707pt;"><i>lograr? ¿Y por qué?</i></span> 
- <span style="font-size:11.142857551574707pt;color:#202020ff;"><i>¿Qué quieres hacer este año? ¿Trimestre? ¿Mes? ¿Semana?</i></span> 

<span style="font-size:11.142857551574707pt;color:#202020ff;">Escribe las respuestas a estas preguntas.</span> 
<span style="font-size:11.142857551574707pt;color:#202020ff;">Entonces responde:</span>
- <span style="font-size:11.142857551574707pt;color:#202020ff;"><i>¿Qué quieres hacer con este día?</i></span> 

<span style="font-size:11.142857551574707pt;color:#ffb718ff;"><b>Mejorando el enfoque</b></span>

<span style="font-size:11.142857551574707pt;color:#202020ff;">Una vez que tengas claro lo qué importa, el resto es la ejecución. Seguro que esta parte es fácil para ti.</span> 

<span style="font-size:11.142857551574707pt;color:#202020ff;"><i>¿Qué quieres lograr hoy?</i></span> <span style="font-size:11.142857551574707pt;color:#202020ff;">Planifica eso por la mañana, o mejor aún, la noche anterior.</span> 
<a href="https://mininmamente.us11.list-manage.com/track/click?u=13bc0a11b0785ce6956146549&id=887d3d3b80&e=3ee44a8eed" rel="noopener" class="external-link" target="_blank" style="font-size:11.142857551574707pt;color:#07c89ff;"><u>Haz una lista de 1 a 3 cosas</u></a><span style="font-size:11.142857551574707pt;">: ¿en qué tareas clave debes concentrarte para aprovechar tu tiempo hoy?</span>

<span style="font-size:11.142857551574707pt;color:#202020ff;">Luego, por la mañana, concéntrate en esas tareas de alto impacto. Usa tu tiempo como un recurso limitado que es: tómalo y aprovéchalo al máximo.</span>
<span style="font-size:11.142857551574707pt;color:#202020ff;">Concéntrate en las cosas que importan.</span> 
<span style="font-size:11.142857551574707pt;color:#202020ff;">Elimina todo lo demás y no actúes según los impulsos de posponer las cosas importantes.</span>
<span style="font-size:11.142857551574707pt;color:#202020ff;">Observa cuándo te estás alejando de las tareas de alto impacto y en su lugar, entrena para volver a ellas.</span>

<span style="font-size:11.142857551574707pt;color:#202020ff;">Agrupa las cosas más pequeñas (como el correo electrónico y los mensajes) y dales un tiempo concentrado más tarde para hacerlas, si eso es importante para tu trabajo.</span>

<span style="font-size:11.142857551574707pt;color:#202020ff;">Entrénate para concentrarte y entrénate para saber siempre en qué debes concentrarte.</span>
<span style="font-size:11.142857551574707pt;color:#202020ff;">Y recuerda siempre por qué es significativo.</span>

<span style="font-size:11.142857551574707pt;color:#202020ff;">Y esta es la clave para aprovechar al máximo tu tiempo limitado y poder así, tener un impacto significativo en el mundo.</span>

<span style="font-size:11.142857551574707pt;color:#ffb718ff;">En un entorno globalizado y descentralizado como el actual, tenemos que ser conscientes que nuestra</span> <span style="font-size:11.142857551574707pt;color:#ffb718ff;"><b>productividad</b></span> <span style="font-size:11.142857551574707pt;color:#ffb718ff;">se ve afectada por las</span> <span style="font-size:11.142857551574707pt;color:#ffb718ff;"><b>personas</b></span> <span style="font-size:11.142857551574707pt;color:#ffb718ff;">con las que</span> <span style="font-size:11.142857551574707pt;color:#ffb718ff;"><b>trabajamos</b></span><span style="font-size:11.142857551574707pt;color:#ffb718ff;">, nos</span> <span style="font-size:11.142857551574707pt;color:#ffb718ff;"><b>relacionamos</b></span> <span style="font-size:11.142857551574707pt;color:#ffb718ff;">y</span> <span style="font-size:11.142857551574707pt;color:#ffb718ff;"><b>compartimos información</b></span><span style="font-size:11.142857551574707pt;color:#ffb718ff;">:</span> 
- <span style="font-size:11.142857551574707pt;color:#ffb718ff;">los miembros de nuestro equipo,</span>  
- <span style="font-size:11.142857551574707pt;color:#ffb718ff;">personal de otros departamentos de nuestra empresas,</span>  
- <span style="font-size:11.142857551574707pt;color:#ffb718ff;">clientes/pacientes,</span>   
- <span style="font-size:11.142857551574707pt;color:#ffb718ff;">proveedores,</span>  
- <span style="font-size:11.142857551574707pt;color:#ffb718ff;">partners,</span>  
- <span style="font-size:11.142857551574707pt;color:#ffb718ff;">entidades financieras,</span>  
- <span style="font-size:11.142857551574707pt;color:#ffb718ff;">agencias externas, etc.</span> 


<span style="font-size:11.142857551574707pt;">De forma que, la</span> <span style="font-size:11.142857551574707pt;"><b>secuencia general</b></span> <span style="font-size:11.142857551574707pt;">para la gestión del tiempo es la siguiente:</span>

<span style="font-size:11.142857551574707pt;">1. Identificar</span> <span style="font-size:11.142857551574707pt;"><b>qué hacemos</b></span><span style="font-size:11.142857551574707pt;">, cuáles son nuestros hábitos.</span> 
<span style="font-size:11.142857551574707pt;">2.</span> <span style="font-size:11.142857551574707pt;"><b>Cómo lo hacemos</b></span><span style="font-size:11.142857551574707pt;">: si lo hacemos bien o si lo hacemos mal y, dentro de esta segunda categoría, aquellas cosas que necesitan ser corregidas.</span> 
<span style="font-size:11.142857551574707pt;">3.</span> <span style="font-size:11.142857551574707pt;"><b>Para qué vamos a actuar</b></span><span style="font-size:11.142857551574707pt;">, es decir, si queremos corregir ciertas cosas, tendremos que saber para qué queremos hacerlo, para establecer planes de mejora, etcétera.</span> 
<span style="font-size:11.142857551574707pt;">4.</span> <span style="font-size:11.142857551574707pt;"><b>Cómo actuaremos:</b></span> <span style="font-size:11.142857551574707pt;">qué técnicas, qué herramientas, qué recursos, qué aplicaciones vamos a utilizar.</span> 
<span style="font-size:11.142857551574707pt;">5.</span> <span style="font-size:11.142857551574707pt;"><b>Cuándo</b></span><span style="font-size:11.142857551574707pt;">, hay que poner un plazo para empezar a aplicar todas estas técnicas para la mejora de la gestión del tiempo.</span>
