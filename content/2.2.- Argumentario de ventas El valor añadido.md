<span style="font-size:15.428571701049805pt;"><b>¿Qué es el argumentario de ventas?</b></span>

<span style="font-size:11.142857551574707pt;">Herramienta para concretar el mensaje que queremos transmitir a nuestro público objetivo</span>

<span style="font-size:11.142857551574707pt;">{{NotesAttachment:5d932cb0ba3b17263cdfda2ee75730d2}}</span>
<span style="font-size:11.142857551574707pt;">A partir de la información que conseguimos al seguir el</span> <a href="https://www.evernote.com/shard/s52/sh/c0225112-0974-4924-8316-3fe29251fd1c/4786fdb593c4c3f95c7338733e10bfdf" rel="noopener" class="external-link" target="_blank" style="font-size:11.142857551574707pt;"><u>proceso de autoconocimiento</u></a> <span style="font-size:11.142857551574707pt;">hay que realizar las siguientes tareas/actividades:</span>


| <span style="color:#333333ff;">A: Localizar</span> <span style="color:#333333ff;"><b>todas</b></span> <span style="color:#333333ff;">las características que nos definen.</span> |
| -- |
| <span style="color:#333333ff;">B:  Escogemos solo las</span> <span style="color:#333333ff;"><b>diferenciales</b></span><span style="color:#333333ff;">. Aquellas en las que somos muy buenos.</span> |
| <span style="color:#333333ff;">C: Transformamos esas características diferenciales en</span> <span style="color:#333333ff;"><b>beneficios</b></span> <span style="color:#333333ff;">para mi público objetivo.</span> |
| <span style="color:#333333ff;">D : Demostrar que son</span> <span style="color:#333333ff;"><b>auténticos</b></span> <span style="color:#333333ff;"><b>beneficios</b></span><span style="color:#333333ff;">.</span>
<span style="color:#333333ff;"><i>No se trata de decir: "yo sé hacer esto",</i></span> 
<span style="color:#333333ff;"><i>más bien: "como yo sé hacer esto, te aportará este valor a ti”.</i></span> |


<span style="font-size:11.142857551574707pt;">Aunque parece un poco difícil demostrarlo, a través de Internet y herramientas como</span> <span style="font-size:11.142857551574707pt;color:#fb5f2cff;"><b>LinkedIn</b></span> <span style="font-size:11.142857551574707pt;">o como los</span> <span style="font-size:11.142857551574707pt;"><b>blogs</b></span> <span style="font-size:11.142857551574707pt;">o</span> <span style="font-size:11.142857551574707pt;"><b>websites</b></span> <span style="font-size:11.142857551574707pt;">personales, podemos:</span>
<span style="font-size:11.142857551574707pt;">- recopilar recomendaciones de personas que nos conocen, profesionales que han trabajado con nosotros,</span> 
<span style="font-size:11.142857551574707pt;">- aportar valor mediante el marketing de contenidos: artículos, posts, sugerencias, etc.</span> 


<span style="font-size:15.428571701049805pt;"><b>Resumen:</b></span>
<span style="font-size:11.142857551574707pt;">Primero se deben identificar las características que definen a cada persona y encontrar aquellas que marcan la diferencia.</span> 
<span style="font-size:11.142857551574707pt;">Lo importante es ofrecer algo deseable para otras personas cercanas y obtener el respaldo para demostrar la valía de cada uno.</span> 
<span style="font-size:11.142857551574707pt;">La participación en foros especializados o el desarrollo de un blog en el que se recomienden las aportaciones de cada uno aportará valor y respaldo a la marca personal.</span>
