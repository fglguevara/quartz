<span style="font-family:Arial-BoldMT;font-size:12pt;"><b>Método 8D, 8 disciplinas para la resolución de problemas.</b></span>

<span style="font-size:11.142857551574707pt;">- Origen en la industria de armamentos, durante la Segunda Guerra Mundial en Estados Unidos, como un sistema para evitar las reclamaciones o las disconformidades.</span> 
<span style="font-size:11.142857551574707pt;">- La empresa Ford tomó este método y lo convirtió durante los años 60-70, en el estándar del sector automovilístico.</span> 
<span style="font-size:11.142857551574707pt;">- Durante los años 90 se readaptó. Se denomina el método Global 8 disciplinas para resolución de problemas.</span>

<span style="font-size:11.142857551574707pt;">{{NotesAttachment:9c4e1539a165b6a90ce7bd37047e16f6}}</span>

<span style="font-family:ArialMT;font-size:11.142857551574707pt;">Es un método que se utiliza para resolver problemas en sectores industriales. Por lo tanto, para problemas simples no es el método más adecuado, pero sí que es útil conocer cómo se va realizando. Se puede adaptar eliminando lo que no sea necesario.</span> 

<span style="font-family:ArialMT;font-size:11.142857551574707pt;">Para conocer este método vamos a dividir su análisis en tres partes:</span> 

<span style="font-size:11.142857551574707pt;">1- la identificación de los problemas,</span> 
<span style="font-size:11.142857551574707pt;">2- análisis de las causas y</span> 
<span style="font-size:11.142857551574707pt;">3- la implementación de las soluciones.</span>

<span style="font-family:ArialMT;font-size:11.142857551574707pt;">En primer lugar</span> <span style="font-family:Arial-BoldMT;font-size:11.142857551574707pt;"><b>documentar</b></span> <span style="font-family:ArialMT;font-size:11.142857551574707pt;">los síntomas que vamos detectando y tomar acciones de contención urgente.</span> 

<span style="font-family:ArialMT;font-size:11.142857551574707pt;">S</span><span style="font-family:Arial-BoldMT;font-size:11.142857551574707pt;"><b>íntoma</b></span> <span style="font-family:ArialMT;font-size:11.142857551574707pt;">es una señal que te sirve para darte cuenta que está habiendo un problema.</span> 

<span style="font-family:ArialMT;font-size:11.142857551574707pt;">La</span> <span style="font-family:Arial-BoldMT;font-size:11.142857551574707pt;"><b>captación</b></span> <span style="font-family:ArialMT;font-size:11.142857551574707pt;">de estas señales se puede hacer mediante:</span>

<span style="font-size:11.142857551574707pt;">- Insatisfacción de los clientes</span>
<span style="font-size:11.142857551574707pt;">Causas:    demoras en las entregas,</span> 
            <span style="font-size:11.142857551574707pt;">falta de calidad,</span>
            <span style="font-size:11.142857551574707pt;">precios altos,</span> 
            <span style="font-size:11.142857551574707pt;">mal clima en la organización,</span> 
            <span style="font-size:11.142857551574707pt;">errores humanos o de procedimiento.</span> 


<span style="font-size:11.142857551574707pt;">Las herramientas para hacer esta detección pueden ser tormentas de ideas,  memorias de actuación o registros de reclamaciones.</span>

<span style="font-family:ArialMT;font-size:11.142857551574707pt;">Detectadas esas señales, lo que vamos a hacer es</span> <span style="font-family:Arial-BoldMT;font-size:11.142857551574707pt;"><b>contener</b></span> <span style="font-family:ArialMT;font-size:11.142857551574707pt;">los efectos de ese problema, esa</span> <span style="font-family:Arial-BoldMT;font-size:11.142857551574707pt;"><b>contención urgent</b></span><span style="font-family:ArialMT;font-size:11.142857551574707pt;">e, medidas que paren esos efectos.</span> 

<span style="font-family:ArialMT;font-size:11.142857551574707pt;">Luego vamos a</span> <span style="font-family:Arial-BoldMT;font-size:11.142857551574707pt;"><b>formar</b></span> <span style="font-family:ArialMT;font-size:11.142857551574707pt;">un</span> <span style="font-family:Arial-BoldMT;font-size:11.142857551574707pt;"><b>equipo</b></span><span style="font-family:ArialMT;font-size:11.142857551574707pt;">, que tiene que estar compuesto por expertos que van a analizar el problema. Liderados por una persona, un responsable, al que se le habrán dado recursos, un tiempo y que se dotará a ese equipo de un procedimiento para analizar ese problema.</span> 

<span style="font-family:ArialMT;font-size:11.142857551574707pt;">Formación de equipos multidisciplinares para la resolución de problemas necesaria en problemas complejos, en los casos en los que haya procedimientos diversos que se ven afectados por ese problema, en el caso de que se haya intentado previamente la resolución de esas circunstancias de forma individual y no se haya podido llegar a ella.</span> 


<span style="font-family:Arial-BoldMT;font-size:11.142857551574707pt;"><b>Definición íntegra del problema</b></span><span style="font-family:ArialMT;font-size:11.142857551574707pt;">. Mediante una descripción completa y cuantificada de esas circunstancias que afectan al procedimiento que analizamos.</span> 
<span style="font-family:ArialMT;font-size:11.142857551574707pt;">La toma de datos para esa descripción la vamos a hacer en contacto con los interesados directos: aquellas personas implicadas en los procedimientos y utilizaremos</span> <span style="font-family:Arial-BoldMT;font-size:11.142857551574707pt;"><b>cuadros de datos, la herramienta de las 5W y 2H,</b></span> <span style="font-family:ArialMT;font-size:11.142857551574707pt;">etc.</span>


<span style="font-family:ArialMT;font-size:11.142857551574707pt;">Y, por último, implementaremos y verificaremos una</span> <span style="font-family:Arial-BoldMT;font-size:11.142857551574707pt;"><b>acción de contención provisional</b></span><span style="font-family:ArialMT;font-size:11.142857551574707pt;">.</span> 
<span style="font-family:ArialMT;font-size:11.142857551574707pt;">Antes habíamos visto que era una acción de urgencia, ahora vamos a establecer unas medidas que van a ser útiles para paliar los efectos y vamos a documentar esas medidas para que, posteriormente, cuando se adapte la medida correctiva definitiva, podamos removerlas, podamos eliminarlas.</span> 

<span style="font-family:ArialMT;font-size:11.142857551574707pt;">El equipo continua trabajando en la búsqueda de soluciones definitivas.</span>
