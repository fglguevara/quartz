<span style="font-size:11.142857551574707pt;">La</span> <span style="font-size:11.142857551574707pt;"><b>Ley de Parkinson</b></span><span style="font-size:11.142857551574707pt;">, enunciada por el historiador británico Cyril Northcote</span> <span style="font-size:11.142857551574707pt;"><b>Parkinson</b></span> <span style="font-size:11.142857551574707pt;">en 1957</span>

<span style="font-size:11.142857551574707pt;">“El trabajo se expande hasta llenar el tiempo disponible para que se termine/para su culminación”:</span>


<span style="font-size:11.142857551574707pt;">Su reflexión ayuda a entender porqué se posponen tareas y se pierde tanto el tiempo.</span>

<span style="font-size:11.142857551574707pt;">{{NotesAttachment:c3d4d86ea5ac8f351daaa11eb9d417aa}}</span>

- <span style="font-size:11.142857551574707pt;">Cuanto menos tiempo se tiene para realizar una tarea mayor es el esfuerzo para concluirla.</span> 
- <span style="font-size:11.142857551574707pt;">Mientras que cuando se tiene más tiempo, menos esfuerzo se realiza para llevarla a cabo.  Incluso, si una tarea se podría haber hecho en 3 horas y se da una semana de plazo, psicológicamente la tarea se expande en dificultad y aparece más difícil de lo que en realidad para que parezca lógico que debe realzarse en una semana de tiempo.</span> 
	- <span style="font-size:11.142857551574707pt;">Podemos detectar con frecuencia casos reales que demuestran que poner plazos muy largos para ejecutar una tarea reduce la eficiencia del trabajo. Además, ampliar artificialmente estos plazos no asegura que finalmente se cumplan: siempre encontraremos la forma de complicar la tarea, pensando y repensando la tarea que tenemos que hacer, demorándonos y manteniéndonos ocupados más del tiempo que sería necesario.</span> 
	- <span style="font-size:11.142857551574707pt;">A esto hay que sumarle que existe una tendencia a procrastinar/postergar las tareas y a ocupar el tiempo en otras tareas que distraen del objetivo principal.</span> 



<span style="font-size:11.142857551574707pt;color:#ffb718ff;"><b>¿Cómo aplicar la Ley de Parkinson?</b></span>

<span style="font-size:11.142857551574707pt;">Lo primero que hay que hacer es marcarse un objetivo para que la tarea no se dilate en el tiempo.  Además existe una norma básica que si una tarea requiere poco tiempo para realizarla hay que hacerla de inmediato sin planificación.</span> 

<span style="font-size:11.142857551574707pt;">Así se ahorra tiempo y se reduce el húmero de tareas pendientes.</span>
<span style="font-size:11.142857551574707pt;">También se crea una rutina y se adquieren hábitos de trabajo.</span>


<span style="font-size:11.142857551574707pt;color:#5ff97ff;"><b>Marcarnos deadlines estrictos. Evitar alargar el tiempo de trabajo:</b></span> <span style="font-size:11.142857551574707pt;color:#5ff97ff;">es importante ser estricto con el tiempo útil de trabajo para aprovecharlo al máximo y evitar postergar tareas. De este modo, se logra finalizar las tareas en menos tiempo y dedicándoles menos tiempo. Así se logra ser más eficiente y alcanzar las metas marcadas.</span> <span style="font-size:11.142857551574707pt;color:#5ff97ff;"><b>Intenta marcarte un tiempo para cada tarea que suponga un reto</b></span> <span style="font-size:11.142857551574707pt;color:#5ff97ff;">viable.</span>

<span style="font-size:11.142857551574707pt;color:#5ff97ff;">Tomar tiempo para evaluar nuestras capacidades y el número de horas que se pueden emplear para realizar una tarea.</span>
<span style="font-size:11.142857551574707pt;color:#5ff97ff;">Las siguientes preguntas pueden ser útiles:</span>

<span style="font-size:11.142857551574707pt;color:#5ff97ff;">-¿Cuánto me ha llevado realizar un proyecto como este en el pasado?</span>
<span style="font-size:11.142857551574707pt;color:#5ff97ff;">-¿Se pudo eliminar o saltar algún paso o tarea?</span>
<span style="font-size:11.142857551574707pt;color:#5ff97ff;">-¿Cuáles son las fortalezas y debilidades en relación con este proyecto?</span>
<span style="font-size:11.142857551574707pt;color:#5ff97ff;">-¿Qué obstáculos y desafíos tendré que hacer frente?</span>
<span style="font-size:11.142857551574707pt;color:#5ff97ff;">-¿Existen algunas restricciones de tiempo?</span>
<span style="font-size:15.428571701049805pt;color:#5ff97ff;">-</span><span style="font-size:11.142857551574707pt;color:#5ff97ff;">Para realizar este proyecto, ¿puedo esforzarme más que habitualmente?</span> 
<span style="font-size:11.142857551574707pt;">Otra regla que nos puede servir para aplicar la Ley de Parkinson es la Regla de Pareto</span>
<span style="font-size:11.142857551574707pt;color:#ffb718ff;"><b>La Regla de Pareto</b></span>
<span style="font-size:11.142857551574707pt;">{{NotesAttachment:e044a6f7e226705aa6c9153c645fb188}}</span>

<span style="font-size:11.142857551574707pt;color:#08a8cff;"><b>Limita las tareas menos productivas</b></span> <span style="font-size:11.142857551574707pt;color:#08a8cff;">asignando un tiempo máximo entre 30 minutos y 1 hora al día.</span> 
<span style="font-size:11.142857551574707pt;color:#08a8cff;">Generalmente son tareas repetitivas como revisar el correo, redes sociales, etc. Se trata de sumideros de tiempo muy peligrosos que podrían arruinar tu productividad personal.</span> 
<span style="font-size:11.142857551574707pt;color:#08a8cff;">Relacionada con este tema tenemos la</span> <span style="font-size:11.142857551574707pt;color:#08a8cff;"><b>Regla 80/20:</b></span> <span style="font-size:11.142857551574707pt;color:#08a8cff;">A esta regla se la conoce como la Ley de Pareto.</span> 
<span style="font-size:11.142857551574707pt;color:#08a8cff;">Vilfredo Pareto ( fue un economista y filósofo que expuso que el 80% de los resultados de una tarea proceden de hacer un esfuerzo correspondiente al 20% del tiempo dedicado.</span> 
<span style="font-size:11.142857551574707pt;">{{NotesAttachment:4befd2aac636674035220c092f874c91}}</span>

<span style="font-size:11.142857551574707pt;color:#08a8cff;">La aplicación práctica de la regla de Pareto exige:</span>
- <span style="font-size:11.142857551574707pt;color:#08a8cff;">Considerar todas las tareas involucradas en un proyecto.</span> 
- <span style="font-size:11.142857551574707pt;color:#08a8cff;">Identificar las más importantes</span> 
- <span style="font-size:11.142857551574707pt;color:#08a8cff;">Enfoca tu tiempo en las tareas que realmente importan y elimina el resto.</span> 
<span style="font-size:11.142857551574707pt;color:#08a8cff;">La clave de esta teoría está en concentrarse y prestar la máxima atención durante el 20% y en menor medida el 80% restante.</span> 

<span style="font-size:11.142857551574707pt;color:#08a8cff;">De esta manera, se concentra un mayor esfuerzo en un periodo corto de tiempo y se logra diferenciar lo importante de lo que no lo es.</span>



<span style="font-size:11.142857551574707pt;color:#ff930ff;">Haz un seguimiento de en qué empleas tu tiempo (Track your time)</span>
<span style="font-size:11.142857551574707pt;">{{NotesAttachment:aa43b4de1555be7f3f38d00c18652a63}}</span>
<span style="font-size:11.142857551574707pt;color:#ff930ff;">Para saber exactamente cómo estás empleando cada hora del día.</span> 
<span style="font-size:11.142857551574707pt;color:#ff930ff;">¿Qué valor obtengo de cada una de las tareas que realizo?</span>

<span style="font-size:11.142857551574707pt;color:#ff930ff;">¿Cuál es el retorno de la inversión de todas las tareas de mi lista de tareas?</span>
<span style="font-size:11.142857551574707pt;color:#ff930ff;">¿Qué valor me aporta en mi vida personal? ¿Y en mi vida profesional?</span> 


<span style="font-size:11.142857551574707pt;">{{NotesAttachment:d5914d062df7da9ebd075a307810153a}}</span>

<span style="font-size:11.142857551574707pt;">Al realizar este análisis comenzaremos a darnos cuenta que empleamos mucho esfuerzo en tareas innecesarias que pueden ser eliminadas.</span> 
<span style="font-size:11.142857551574707pt;">{{NotesAttachment:dd89503bed8765aa55d6b510ac73bbc1}}{{NotesAttachment:81e93c6af1bea9eb0f71d47e48341c85}}</span>
<span style="font-size:11.142857551574707pt;">Limitar el número de actividades consumidoras de tiempo y de poco valor:</span>

- <span style="font-size:11.142857551574707pt;">Redes sociales.</span> 
- <span style="font-size:11.142857551574707pt;">Wallapop.</span> 
- <span style="font-size:11.142857551574707pt;">Revisar continuamente el correo electrónico.</span>  
- <span style="font-size:11.142857551574707pt;">Leer titulares de noticias</span> 
<span style="font-size:11.142857551574707pt;">Poner un límite a esas actividades facilitará dedicar tiempo a las actividades importantes y tener tiempo para la vida personal, familiar, el deporte, el ocio y la vida espiritual.</span>



<span style="font-size:11.142857551574707pt;">Utiliza la técnica conocida como</span> <span style="font-size:11.142857551574707pt;"><b><i>“eat the frog”</i></b></span> <span style="font-size:11.142857551574707pt;">(traducida literalmente como</span> <span style="font-size:11.142857551574707pt;"><i>cómete la rana</i></span><span style="font-size:11.142857551574707pt;">). Consiste en hacer siempre primero lo más importante.</span>
<span style="font-size:11.142857551574707pt;">{{NotesAttachment:74c3bb8692e5fefe7cdd9527b718ac98}}</span>



<span style="font-size:11.142857551574707pt;"><b>Técnica de TimeBlocking:</b></span> <span style="font-size:11.142857551574707pt;">poner una fecha y hora limitada a tus tareas. Por ejemplo, es correcto marcarse como propósito escribir un Post en un día determinado, pero es preferible asignar a la tarea un tiempo limitado, así evitarás caer en los efectos negativos de la Ley de Parkinson.</span>
<span style="font-size:11.142857551574707pt;">{{NotesAttachment:21db61de881e08a09d9d9ca5c8a8cb0f}}</span>




<span style="font-size:11.142857551574707pt;"><b>Divide las tareas más complejas.</b></span> <span style="font-size:11.142857551574707pt;">Son las más peligrosas puesto que requerirán mucho tiempo y la influencia de la Ley de Parkinson será mucho mayor. Anota en tu bloque te tiempo qué sub-tarea vas a realizar. Esto enfocará tu trabajo.</span>


<span style="font-size:11.142857551574707pt;"><b>Confecciona una regla de límite de tiempo</b></span>
<span style="font-size:11.142857551574707pt;">{{NotesAttachment:646d2695ea770a8b0faaf621a47cce63}}</span>

<span style="font-size:11.142857551574707pt;"><b>Definir una regla con un límite de tiempo para realizar una tarea, por ejemplo revisar el correo electrónico o devolver llamadas telefónicas (o sacar a la mascota).</b></span>
<span style="font-size:11.142857551574707pt;"><b>Se trata de definir el tiempo que empleamos en realizar una tarea cotidiana (repetitiva) que debe ser realizada.</b></span>
<span style="font-size:11.142857551574707pt;"><b>Una vez que acaba el tiempo, se abandona la tarea y se comienza el trabajo productivo.</b></span>
<span style="font-size:11.142857551574707pt;"><b>También se puede definir una regla para acabar el trabajo a una cierta hora. Cuando se alcanza esa hora, se abandona el trabajo y comienza el tiempo libre.</b></span>

<span style="font-size:11.142857551574707pt;"><b>Eso es muy importante para diferenciar el trabajo de la vida privada, especialmente con el teletrabajo (COVID).</b></span>



<span style="font-size:11.142857551574707pt;">{{NotesAttachment:f2b733d04193c712547c0fe64c521201}}</span>

<span style="font-size:11.142857551574707pt;"><b>Aprovechar las horas de mayor productividad:</b></span> <span style="font-size:11.142857551574707pt;">cada persona rinde de una manera distinta y no tienen porqué coincidir en las mismas franjas horarias. Por ese motivo, es importante aprovechar las horas de mayor productividad para realizar las tareas y así lograr mejores resultados.</span>


<span style="font-size:11.142857551574707pt;">Evitar el</span> <span style="font-size:11.142857551574707pt;"><b>perfeccionismo.</b></span> <span style="font-size:11.142857551574707pt;">Haz que tu proyecto se base en la filosofía</span> <a href="https://www.edusalado.com/gestion-empresarial/lean-starup-en-proyectos-online/" rel="noopener" class="external-link" target="_blank" style="font-size:11.142857551574707pt;"><b><u>LEAN</u></b></a><span style="font-size:11.142857551574707pt;">. Especialmente en proyectos online, ser excesivamente perfeccionista o querer incorporar demasiadas prestaciones inicialmente a tu proyecto, harán que el tiempo de lanzamiento se alargue innecesariamente.</span>
<span style="font-size:11.142857551574707pt;">{{NotesAttachment:02a36bebd18414112ff426a0306ab77e}}</span>


<span style="font-size:11.142857551574707pt;color:#ffb718ff;"><b>Resumen:</b></span>
<span style="font-size:11.142857551574707pt;">Gestionar las tareas y su relación con el tiempo es más complejo cuando trabajas en una organización grande. Coordinar tu agenda con la de un equipo grande de trabajo es complejo. Y es más complicado cuanto más vertical sea la organización. Lo ideal será dar libertad a tu equipo para gestionar su agenda de trabajo cumpliendo ciertos hitos, pero ésta es una práctica que es difícil encontrar.</span> 

<span style="font-size:11.142857551574707pt;">Evitar lo que te perjudica y anticiparse a aquellas conductas que conducen a la procrastinación son las claves para hacer frente a la Ley de Parkinson en el trabajo o en cualquier otro ámbito. Para cumplir con los objetivos marcados se debe marcar prioridades y optimizar al máximo los espacios de tiempo que se dedican a realizar esas tareas evitando las distracciones. De esta manera, se reducirá el tiempo.</span>
