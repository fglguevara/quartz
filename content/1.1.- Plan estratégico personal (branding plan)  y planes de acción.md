<span style="font-size:11.142857551574707pt;">Toda persona tiene una vocación o misión específica en la vida. Toda persona debe llevar a cabo un designio concreto que exige su cumplimiento. Por ello es irremplazable, y su vida, irrepetible. De este modo, la tarea de cada persona es única así como la oportunidad específica de realizarla.</span>

<span style="font-size:11.142857551574707pt;">{{NotesAttachment:1f60732e7ae797c9c884561b61edd641}}{{NotesAttachment:59b784618f42cea59dd49ad099a482d4}}</span>


<span style="font-size:15.428571701049805pt;color:#e2432ff;"><b>¿Qué es Personal Branding?</b></span> 
<span style="font-size:11.142857551574707pt;">La</span> <span style="font-size:11.142857551574707pt;"><b>Marca Personal</b></span> <span style="font-size:11.142857551574707pt;">(en inglés,</span> <span style="font-size:11.142857551574707pt;"><i>Personal Branding</i></span><span style="font-size:11.142857551574707pt;">) es un concepto de</span> <span style="font-size:11.142857551574707pt;"><b>desarrollo</b></span> <span style="font-size:11.142857551574707pt;"><b>personal</b></span> <span style="font-size:11.142857551574707pt;">que consiste en considerarse uno mismo como una</span> <span style="font-size:11.142857551574707pt;"><b>marca</b></span><span style="font-size:11.142857551574707pt;">, que al igual que las marcas comerciales, debe ser  elaborada, transmitida y protegida,</span> 

<span style="font-size:11.142857551574707pt;"><b>➡️</b></span>   <span style="font-size:11.142857551574707pt;">diferenciarse y conseguir mayor éxito en las relaciones sociales y profesionales.</span>


<span style="font-size:15.428571701049805pt;color:#e2432ff;"><b>¿Para qué?</b></span>
<span style="font-size:11.142857551574707pt;">Un</span> <span style="font-size:11.142857551574707pt;"><b>plan estratégico persona</b></span><span style="font-size:11.142857551574707pt;">l o</span> <span style="font-size:11.142857551574707pt;"><i>branding plan</i></span> <span style="font-size:11.142857551574707pt;">nos permite:</span>
- <span style="font-size:11.142857551574707pt;">Autoconocimiento: Analizar</span> <span style="font-size:11.142857551574707pt;color:#ca28e9ff;"><b>quiénes somos</b></span><span style="font-size:11.142857551574707pt;">: debilidades, fortalezas ➕  amenazas, oportunidades.</span> 
- <span style="font-size:11.142857551574707pt;">Determinar a dónde queremos llegar: elaborar un conjunto de</span> <span style="font-size:15.428571701049805pt;color:#ca28e9ff;"><b>objetivos</b></span> <span style="font-size:11.142857551574707pt;">alcanzables. Objetivos claros, concisos, motivadores, viables.</span> 
- <span style="font-size:11.142857551574707pt;">En cualquier momento, Identificar/Medir la</span> <span style="font-size:11.142857551574707pt;color:#ca28e9ff;"><b>distancia entre dónde estamos y dónde queremos llegar.</b></span> 

<span style="font-size:11.142857551574707pt;"><i>Herramienta útil para nuestro desarrollo personal y profesional.</i></span>

<span style="font-size:11.142857551574707pt;">Para alcanzar nuestros objetivos debemos definir un</span> <span style="font-size:11.142857551574707pt;color:#ca28e9ff;"><b>plan de acción</b></span>



<span style="font-size:11.142857551574707pt;">{{NotesAttachment:5e3ca1526173d18ed9355035221bd98a}}</span>
<span style="font-size:15.428571701049805pt;color:#e2432ff;"><b>¿Quién necesita un plan estratégico personal?</b></span> 

<span style="font-size:11.142857551574707pt;">Muchas insatisfacciones vienen producidas porque no tenemos claros:</span>
- <span style="font-size:11.142857551574707pt;color:#ff02aff;">objetivos</span> <span style="font-size:11.142857551574707pt;">(donde queremos llegar)</span> 
- <span style="font-size:11.142857551574707pt;color:#ca28e9ff;">prioridades</span>  

<span style="font-size:11.142857551574707pt;color:#616161ff;">Un plan estratégico es</span> <span style="font-size:11.142857551574707pt;color:#616161ff;"><u>válido para todo el mundo</u></span> <span style="font-size:11.142857551574707pt;color:#616161ff;">siempre y cuando sea una herramienta útil, no una herramienta que agobie o inmovilice.</span>


<span style="font-size:15.428571701049805pt;color:#e2432ff;"><b>¿Porqué?</b></span>

<span style="font-size:11.142857551574707pt;">Si la ausencia de objetivos genera un malestar es necesario tener un plan estratégico.</span> 

<span style="font-size:11.142857551574707pt;">La falta de atención y de planificación -especialmente en los entornos laborales- pueden conducir a resultados no deseados (insatisfacción, frustración, etc.)</span> 

<span style="font-size:11.142857551574707pt;">Si tenemos capacidad de influencia y no planificamos es una irresponsabilidad.</span> 
<span style="font-size:11.142857551574707pt;">Pero, ¿tenemos capacidad de influencia? ¿en qué aspectos de nuestra vida personal y laboral?</span>



<span style="font-size:11.142857551574707pt;">{{NotesAttachment:478b2db0119d510c91282fb9148a9252}}</span>
<span style="font-size:15.428571701049805pt;color:#e2432ff;"><b>¿Cuándo?</b></span>

<span style="font-size:11.142857551574707pt;">Hay que elegir el momento adecuado para perseguir una acción.</span> 
<span style="font-size:11.142857551574707pt;">Depende del momento vital y cuales son nuestras prioridades en ese momento.</span>
<span style="font-size:11.142857551574707pt;">Cómo nos encontramos.</span> 


<span style="font-size:15.428571701049805pt;color:#e2432ff;"><b>¿Cómo?</b></span>

<span style="font-size:11.142857551574707pt;">La elaboración del plan lleva su</span> <span style="font-size:11.142857551574707pt;color:#ff02aff;">tiempo</span> <span style="font-size:11.142857551574707pt;">y</span> <span style="font-size:11.142857551574707pt;color:#ff02aff;">esfuerzo</span><span style="font-size:11.142857551574707pt;">.</span>
<span style="font-size:11.142857551574707pt;">Se requiere</span> <span style="font-size:11.142857551574707pt;color:#ff02aff;">reflexión personal</span><span style="font-size:11.142857551574707pt;">.</span> 
<span style="font-size:11.142857551574707pt;">Hay que identificar</span> <span style="font-size:11.142857551574707pt;"><u>aspectos</u></span> <span style="font-size:11.142857551574707pt;">de nuestra vida que pueden</span> <span style="font-size:11.142857551574707pt;"><u>resultar no agradables</u></span><span style="font-size:11.142857551574707pt;">.</span> 

- <span style="font-size:11.142857551574707pt;color:#ffb718ff;"><b>Autoconocimiento</b></span><span style="font-size:11.142857551574707pt;">: En qué aspectos nos debemos fijar para conocernos mejor.</span> 
- <span style="font-size:11.142857551574707pt;">Establecimiento de</span> <span style="font-size:11.142857551574707pt;color:#ffb718ff;"><b>objetivos</b></span><span style="font-size:11.142857551574707pt;">: áreas: personales, profesionales, familiares, salud personal, relaciones, espirituales.</span> 
- <span style="font-size:11.142857551574707pt;">Articular un</span> <span style="font-size:11.142857551574707pt;color:#ffb718ff;"><b>plan de acción</b></span><span style="font-size:11.142857551574707pt;">.</span> 
- <span style="font-size:11.142857551574707pt;color:#ffb718ff;"><b>Apoyos</b></span> <span style="font-size:11.142857551574707pt;">durante el proceso: profesionales y equipos de trabajo.  En el plan estratégico se identifican nuestros recursos y apoyos para alcanzar los objetivos.</span>
