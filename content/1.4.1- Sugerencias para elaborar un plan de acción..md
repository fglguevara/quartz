<span style="font-size:15.428571701049805pt;">Un plan de acción¹ es una herramienta administrativa que establece el camino para conseguir las metas de una organización. Para</span> <span style="font-size:15.428571701049805pt;"><b>redactar</b></span> <span style="font-size:15.428571701049805pt;">un plan de</span> <span style="font-size:15.428571701049805pt;"><b>acción</b></span> <span style="font-size:15.428571701049805pt;">para conseguir un objetivo en una organización del sector salud, se pueden seguir los siguientes</span> <span style="font-size:15.428571701049805pt;"><b>pasos</b></span><span style="font-size:15.428571701049805pt;">²:</span>



| <span style="font-size:18pt;color:#fb5f2cff;"><b>Definir el objetivo a lograr</b></span><span style="font-size:18pt;color:#fb5f2cff;">, que sea específico, medible, alcanzable, relevante y con un plazo determinado; es decir que sea SMART</span> |
| -- |
| <span style="font-size:18pt;color:#fb5f2cff;"><b>Identificar</b></span> <span style="font-size:18pt;color:#fb5f2cff;">las</span> <span style="font-size:18pt;color:#fb5f2cff;"><b>tareas</b></span> <span style="font-size:18pt;color:#fb5f2cff;">o acciones que se deben realizar para alcanzar el objetivo, asignando</span> <span style="font-size:18pt;color:#fb5f2cff;"><b>responsables</b></span><span style="font-size:18pt;color:#fb5f2cff;">,</span> <span style="font-size:18pt;color:#fb5f2cff;"><b>recursos</b></span> <span style="font-size:18pt;color:#fb5f2cff;">y</span> <span style="font-size:18pt;color:#fb5f2cff;"><b>fechas de entrega</b></span> <span style="font-size:18pt;color:#fb5f2cff;">para cada una.</span> |
| <span style="font-size:18pt;color:#fb5f2cff;">Establecer los</span> <span style="font-size:18pt;color:#fb5f2cff;"><b>indicadores</b></span> <span style="font-size:18pt;color:#fb5f2cff;">o medidas que permitan</span> <span style="font-size:18pt;color:#fb5f2cff;"><b>evaluar el progreso</b></span> <span style="font-size:18pt;color:#fb5f2cff;">y el</span> <span style="font-size:18pt;color:#fb5f2cff;"><b>cumplimiento</b></span> <span style="font-size:18pt;color:#fb5f2cff;">del objetivo.</span> |

| <span style="font-size:18pt;color:#fb5f2cff;">Comunicar y celebrar los resultados obtenidos al finalizar el plan de acción.</span> |
